# Slicewise parameter reference

This document describes the user-facing parameters in Slicewise as implemented in `src/App.tsx` and `src/lib/slicer.ts`. Ranges are the limits enforced by the interface. Unless noted otherwise, changing a parameter redraws the preview and affects both SVG and G-code output.

## Source model

| Parameter (ID)                          | Type and default                   | What it does                                                                                                                                                                                                                                                |
| --------------------------------------- | ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Demo (`demo`)                           | Select; **Torus knot**             | Loads one of the built-in meshes: Torus knot, Ripple sphere, Rounded cube, Soft diamond, Ring torus, Twisted bloom, Hourglass, or Tetrapod. Selecting an uploaded file changes this internally to **Uploaded model**.                                       |
| Generative field (`genField`)           | Select; **Gyroid**                 | Builds a procedural solid from Gyroid, Schwarz P, Diamond, Neovius, Metaballs, Supershape, or **Relief · topographic**. Relief creates a closed circular terrain medallion whose seeded height field is designed for Z-height contour slicing.              |
| Seed (`genSeed`)                        | Integer; **0**; 0–9999             | Reproduces randomized field choices. For Relief it changes the generated landforms while identical seeds and settings produce identical geometry.                                                                                                           |
| Carve (`genBlend`)                      | Number; **35%**; 0–100, step 1     | Controls how deeply volumetric fields cut into their bounding sphere. For Relief it controls the terrain's vertical height range.                                                                                                                           |
| Frequency (`genFreq`)                   | Number; **2**; 0.5–8, step 0.1     | Sets field repetition or feature density. Higher Relief values create more, smaller terrain features.                                                                                                                                                       |
| Z anisotropy (`genAniso`)               | Number; **0%**; −100–100, step 1   | Stretches volumetric field frequency along Z. For Relief it acts as vertical exaggeration, from flatter terrain at negative values to steeper terrain at positive values.                                                                                   |
| Level set (`genIso`)                    | Number; **0**; −1.4–1.4, step 0.01 | Selects the implicit surface threshold. For Relief it raises or lowers the terrain top relative to its base.                                                                                                                                                |
| Twist (`genTwist`)                      | Number; **0°**; −180–180, step 1   | Twists volumetric sampling around Z. For Relief it progressively sweeps terrain features from the centre toward the rim while preserving a single-valued height field.                                                                                      |
| Noise (`genNoise`)                      | Number; **0%**; 0–100, step 1      | Adds seeded fBm displacement to volumetric fields. Relief always includes broad seeded landforms; this control mixes in finer terrain detail.                                                                                                               |
| Resolution (`genRes`)                   | Integer; **96**; 32–192            | Sets the mesh sampling grid per axis. Higher values make generated surfaces and contour paths smoother but take longer to rebuild.                                                                                                                          |
| Model file (`file`)                     | File; none                         | Imports an STL (binary or ASCII), OBJ, PLY (binary or ASCII), or filled SVG. OBJ and PLY files initially use Y-up; STL, SVG, and demos initially use Z-up. Processing stays in the browser. SVG strokes must be converted to filled outlines before import. |
| SVG interpretation (`svgMode`)          | Select; **Extruded shape**         | Converts filled SVG artwork either into a 3D extrusion for contour slicing or into direct single-line artwork derived from its medial/scale axis. Centreline mode starts face-on and bypasses mesh-only contour settings.                                   |
| Extrusion (`svgDepth`)                  | Number; **12%**; 0.5–100, step 0.1 | For an imported SVG, sets extrusion depth as a percentage of the artwork's largest 2D span. This control is hidden for other model types.                                                                                                                   |
| Round extruded edges (`svgRounded`)     | Boolean; **off**                   | Adds a bevel to the front, back, and sides of an imported SVG extrusion.                                                                                                                                                                                    |
| Roundness (`svgRoundness`)              | Number; **25%**; 0–100, step 0.5   | Sets the SVG bevel size relative to the largest safe radius (the smaller of half the extrusion depth and 25% of the SVG span). Enabled only when **Round extruded edges** is on.                                                                            |
| Branch pruning (`svgCenterlinePruning`) | Number; **2**; 1–4, step 0.1       | Controls scale-axis simplification in centreline mode. Higher values remove more small branches caused by fine boundary details while preserving topology.                                                                                                  |
| Model up axis (`upZ` / `upY`)           | Choice; **Z up**                   | Declares whether the source model uses Z or Y as its vertical axis. Y-up input is rotated into Slicewise's internal Z-up coordinate system.                                                                                                                 |

Imported meshes are welded, centred on their bounding-box midpoint, and uniformly normalized to a bounding-sphere radius of 1. Original model units therefore do not determine output size; artboard, margin, scale, and offsets do.

## Morph

| Parameter (ID)                          | Type and default     | What it does                                                                                                                                                                                                                                                                      |
| --------------------------------------- | -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Enable morph instances (`morphEnabled`) | Boolean; **off**     | Generates multiple overlaid contour instances by interpolating selected parameters from their base values to morph targets. At least one parameter must have an active morph target.                                                                                              |
| X steps (`morphSteps`)                  | Integer; **4**; 2–24 | Number of evenly spaced instances along the X morph dimension, including the base and target endpoints. Used only when an X target exists.                                                                                                                                        |
| Add Y dimension (`morphSecondEnabled`)  | Boolean; **off**     | Enables a second, independent target per morphable parameter. X and Y interpolation combine into a matrix of overlaid variations. Turning this off clears Y targets.                                                                                                              |
| Y steps (`morphStepsY`)                 | Integer; **4**; 2–24 | Number of evenly spaced instances along the Y morph dimension, including endpoints. Used only when a Y target exists. Total instances are X steps × Y steps when both dimensions have targets.                                                                                    |
| Per-parameter morph target              | Number or colour     | The arrow beside a morphable control cycles through no target, X target, and—when Y is enabled—X + Y targets. Numeric values interpolate linearly; ink colour interpolates per RGB channel. Each generated instance is placed on the same artboard rather than in a tiled layout. |

Morphable parameters are: Azimuth, Elevation, Roll, Scale, Offset X/Y, Focal length, Perspective, Klein↔Poincaré warp, Hyperbolic direction/displacement/rotation/strength, Lens distortion, Line count, Curve quality, Ease strength/cycles/centre, custom slice Azimuth/Elevation, slice LFO amplitude/cycles/direction/phase and modulation depth/cycles/phase, Stroke, line-weight Interval/Variation, Ink colour, Pen colours, Margin, every numeric generative-mask parameter, Dot spacing, Contrast, Depth cycles, and RGB split. Source-extrusion, artboard-dimension, morph-step, projection-warp mode, categorical line-weight mode, and G-code parameters are not morphable.

## View

| Parameter (ID)                                 | Type and default                       | What it does                                                                                                                                                                                                                                              |
| ---------------------------------------------- | -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Azimuth (`az`)                                 | Number; **35°**; −180–180, step 0.1    | Rotates the camera around the model's Z axis.                                                                                                                                                                                                             |
| Elevation (`el`)                               | Number; **24°**; −180–180, step 0.1    | Rotates the camera above/below and through the model. The full range permits an inverted view.                                                                                                                                                            |
| Roll (`rl`, state key `roll`)                  | Number; **0°**; −180–180, step 0.1     | Rotates the projected view around the camera's viewing direction.                                                                                                                                                                                         |
| Scale (`zoom`)                                 | Number; **1×**; 0.2–3, step 0.01       | Multiplies the model's fitted projection size. The initial 1× fit uses the smaller artboard dimension minus the margin.                                                                                                                                   |
| Offset X (`panX`)                              | Number; **0 mm**; −2000–2000, step 0.1 | Moves the projected model horizontally from the artboard centre. Positive values move it right.                                                                                                                                                           |
| Offset Y (`panY`)                              | Number; **0 mm**; −2000–2000, step 0.1 | Moves the projected model vertically from the artboard centre. Positive values move it down in SVG/artboard coordinates.                                                                                                                                  |
| Focal length (`lensFocalLength`)               | Number; **50 mm**; 8–300, step 1       | Controls perspective continuously. Short focal lengths exaggerate the size difference between near and far geometry; long focal lengths flatten it toward an orthographic view.                                                                           |
| Perspective (`lensPerspective`)                | Number; **0%**; 0–100, step 1          | Blends from exact orthographic projection at 0% to the perspective produced by the focal length at 100%. Intermediate values provide a controlled, softened perspective.                                                                                  |
| Projection warp (`projectionWarpMode`)         | Choice; **None**                       | Selects one exclusive camera-space projection warp: None, Klein ↔ Poincaré, or Hyperbolic Möbius. Old snapshots without this field select Klein ↔ Poincaré when their stored `lensWarpExponent` is nonzero.                                               |
| Klein ↔ Poincaré (`lensWarpExponent`)          | Number; **0%**; 0–100, step 1          | With the matching projection mode selected, applies a radial disk-model warp after perspective. 0% preserves Klein coordinates; 100% uses the standard Klein-to-Poincaré radius conversion; intermediate values use a continuous multiplicative exponent. |
| Hyperbolic direction (`mobiusDirection`)       | Number; **0°**; −180–180, step 1       | Sets the polar direction of the Möbius disk-translation parameter.                                                                                                                                                                                        |
| Hyperbolic displacement (`mobiusDisplacement`) | Number; **0%**; 0–95, step 1           | Sets the disk-translation magnitude. The 95% maximum stays safely inside the open Poincaré disk while allowing strong asymmetric navigation.                                                                                                              |
| Hyperbolic rotation (`mobiusRotation`)         | Number; **0°**; −180–180, step 1       | Rotates the translated Poincaré disk counter-clockwise.                                                                                                                                                                                                   |
| Warp strength (`mobiusStrength`)               | Number; **100%**; 0–100, step 1        | Interpolates the Möbius translation and rotation parameters from identity at 0% to their selected values at 100%. It does not blend final XY coordinates, so every intermediate transform remains disk-preserving.                                        |
| Lens distortion (`lensDistortion`)             | Number; **0%**; −100–100, step 1       | Applies continuous radial optical distortion after the selected projection warp. Negative values create barrel distortion, 0% is neutral, and positive values create pincushion distortion.                                                               |

Canvas gestures provide equivalent controls: drag to change azimuth/elevation, Shift-drag to roll, Space-drag to offset, and use the mouse wheel to scale. Double-click resets Scale and both offsets, but leaves orientation unchanged.

For a classic isometric view, set Perspective to 0%, Lens distortion to 0%, Azimuth to 45°, Elevation to 35.3°, and Roll to 0°. Other orthographic azimuth/elevation combinations produce dimetric, trimetric, plan, and elevation views.

Klein ↔ Poincaré and Hyperbolic Möbius are projection warps of the rendered Euclidean mesh, not replacements for its intrinsic geometry or contour metric. The fixed order is camera basis, orthographic/perspective blend, the selected projection warp, optical lens distortion, then sheet scale and offset. At the Klein ↔ Poincaré 100% endpoint the disk-model relation is `p = k / (1 + sqrt(1 − k²))`. Möbius uses `z′ = exp(iθ) · (z − a) / (1 − conjugate(a) · z)` with a bounded translation parameter `a`. Points on or beyond the unit-disk boundary retain finite, monotonic radial overflow after their direction is transformed. Nonlinear spans are adaptively subdivided according to Curve quality before visibility and output processing, so preview, SVG, and G-code follow the warped curve rather than connecting distant transformed endpoints with straight chords.

## Contours

### Density and finish

| Parameter (ID)            | Type and default       | What it does                                                                                                                                                                                                                  |
| ------------------------- | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Line count (`lines`)      | Integer; **40**; 1–200 | Sets the number of slice levels. In spiral mode it sets the number of turns in the helicoidal slicing field. Higher values increase density and render cost.                                                                  |
| Curve quality (`quality`) | Integer; **7**; 1–10   | Controls curved interpolation and path simplification. A higher value more strongly follows mesh vertex normals, uses a tighter simplification tolerance, and emits more detailed paths. At 1, contour spans remain straight. |

### Line spacing

| Parameter (ID)                 | Type and default                | What it does                                                                                                                                                                                                  |
| ------------------------------ | ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Gap easing (`gapEase`)         | Select; **Linear**              | Redistributes slice levels through the selected scalar range. Options are Linear plus Sine, Quadratic, and Cubic variants: In, Out, In & Out, and Out & In. It changes spacing, not the requested line count. |
| Ease strength (`easeStrength`) | Number; **100%**; 0–300, step 1 | Blends/applies the easing curve. 0% produces linear spacing, 100% applies it once, 200% twice, and 300% three times; intermediate values blend toward the next application.                                   |
| Ease cycles (`easeCycles`)     | Integer; **1**; 1–12            | Repeats the easing pattern this many times across the model's slice range.                                                                                                                                    |
| Ease centre (`easeCenter`)     | Number; **50%**; 5–95, step 1   | Sets the pivot between the two halves of **In & Out** or **Out & In** curves. It is disabled for Linear and one-direction curves.                                                                             |

### Slice field

| Parameter (ID)                              | Type and default                   | What it does                                                                                                                                                                                                                                                                                             |
| ------------------------------------------- | ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Slice field (`axis`)                        | Select; **Height · topographic**   | Chooses the scalar field intersected by the contours: model Z height (`up`), camera depth (`cam`), model X width (`x`), model Y depth (`y`), a custom plane (`custom`), spherical distance (`spherical`), cylindrical radial distance (`cylindrical`), or intrinsic surface-graph distance (`geodesic`). |
| Custom azimuth (`cutAz`)                    | Number; **0°**; −180–180, step 1   | Sets the horizontal direction of the custom slicing normal. Editing it automatically selects **Custom plane angle**.                                                                                                                                                                                     |
| Custom elevation (`cutEl`)                  | Number; **90°**; −90–90, step 1    | Sets the vertical angle of the custom slicing normal. 90° is equivalent to the topographic Z direction. Editing it automatically selects **Custom plane angle**.                                                                                                                                         |
| Centre X/Y/Z (`waveCenterX/Y/Z`)            | Number; **0%**; −100–100, step 1   | Places the spherical centre or a point on the cylindrical axis in model space. Each value is a percentage of the normalized model radius, so 100% reaches the source mesh's normalization sphere.                                                                                                        |
| Cylinder azimuth (`cylinderAzimuth`)        | Number; **0°**; −180–180, step 1   | Sets the horizontal direction of the cylindrical wavefront axis. It appears only for **Cylindrical wavefront**.                                                                                                                                                                                          |
| Cylinder elevation (`cylinderElevation`)    | Number; **90°**; −90–90, step 1    | Sets the vertical direction of the cylindrical wavefront axis. 90° follows model Z.                                                                                                                                                                                                                      |
| Geodesic mode (`geodesicMode`)              | Choice; **Single source**          | Chooses ordinary distance from Seed A, distance to the nearest of A/B, signed `dA − dB`, or the boundary between the two nearest-source regions. The latter three modes reveal Seed B.                                                                                                                   |
| Seed A azimuth (`geodesicSeedAzimuth`)      | Number; **0°**; −180–180, step 1   | Sets the horizontal model-space direction used to choose Seed A. The extreme vertex in that direction is selected deterministically.                                                                                                                                                                     |
| Seed A elevation (`geodesicSeedElevation`)  | Number; **90°**; −90–90, step 1    | Sets the vertical Seed A direction. 90° chooses the extreme model-Z vertex. Equal-distance contours use shortest paths along mesh edges, not ambient 3D radius or a continuous exact geodesic.                                                                                                           |
| Seed B azimuth (`geodesicSeedBAzimuth`)     | Number; **0°**; −180–180, step 1   | Sets the second source's horizontal direction for nearest, difference, and Voronoi modes.                                                                                                                                                                                                                |
| Seed B elevation (`geodesicSeedBElevation`) | Number; **−90°**; −90–90, step 1   | Sets the second source's vertical direction. The opposite model-Z default gives multi-source modes distinct seeds on typical closed meshes.                                                                                                                                                              |
| Divergence (`divergence`)                   | Number; **0°**; 0–160, step 1      | Fans planar slices across the mesh's angular extent from an automatically placed virtual source axis outside the model. It is disabled for spherical, cylindrical, and geodesic fields. 0° keeps the planes parallel; larger angles increase convergence.                                                |
| Modulate slice planes (`sliceLfo`)          | Boolean; **off**                   | Warps a planar cutting field into a periodic implicit surface before it intersects the mesh. It is disabled for spherical, cylindrical, and geodesic fields. The resulting intersections feed visibility, projection, SVG, and G-code directly.                                                          |
| LFO amplitude (`sliceLfoAmplitude`)         | Number; **75% gap**; 0–400, step 1 | Sets cutting-surface displacement relative to one evenly spaced contour interval. Tying depth to line spacing keeps the effect comparable across models and line counts.                                                                                                                                 |
| LFO cycles (`sliceLfoCycles`)               | Number; **2**; 0.25–12, step 0.25  | Sets how many waveform cycles cross the model along the selected in-plane direction. High cycle counts require a sufficiently dense source mesh.                                                                                                                                                         |
| LFO direction (`sliceLfoAngle`)             | Number; **0°**; 0–180, step 1      | Rotates the waveform direction within the cutting plane without changing its normal.                                                                                                                                                                                                                     |
| LFO phase (`sliceLfoPhase`)                 | Number; **0°**; 0–360, step 1      | Moves the waveform across the model while preserving its amplitude and direction.                                                                                                                                                                                                                        |
| LFO waveform (`sliceLfoWaveform`)           | Choice; **Sine**                   | Chooses a smooth sine surface or a continuous triangle surface. Curve quality controls adaptive triangle subdivision, intersection precision, and curve output.                                                                                                                                          |
| Modulate LFO (`sliceLfoModulation`)         | Boolean; **off**                   | Applies a second sine oscillator to the active slice-plane LFO inside the same scalar-field evaluation. It does not run a second slicing pass.                                                                                                                                                           |
| Mode (`sliceLfoModulationMode`)             | Choice; **Amplitude**              | Chooses amplitude modulation, which varies the carrier displacement envelope, or frequency modulation, which applies bounded phase deviation to vary its local spatial frequency.                                                                                                                        |
| Mod depth (`sliceLfoModulationDepth`)       | Number; **50%**; 0–100, step 1     | Controls envelope variation for AM or phase deviation for FM. At 0% the modulator is neutral. AM remains non-inverting through the full range.                                                                                                                                                           |
| Mod cycles (`sliceLfoModulationCycles`)     | Number; **1**; 0.25–8, step 0.25   | Sets how many modulation cycles span the model along the carrier's in-plane direction. Extreme FM combinations may request one additional adaptive refinement level.                                                                                                                                     |
| Mod phase (`sliceLfoModulationPhase`)       | Number; **0°**; 0–360, step 1      | Moves the modulation pattern across the model independently of the carrier phase.                                                                                                                                                                                                                        |

**Distance difference** uses the symmetric range `[-max(|dA − dB|), +max(|dA − dB|)]`, ignores Gap easing, and always includes the meaningful zero contour. When Line count is even, one additional level is emitted so the family remains paired around zero. **Voronoi boundary** emits one explicit boundary family, so Line count and Gap easing are disabled. Equal-distance nearest-source ties belong to the lower seed vertex. Components unreachable from both seeds are omitted; difference and Voronoi output is empty when the seeds do not share a connected component.

### Path construction

| Parameter (ID)               | Type and default | What it does                                                                                                                                                                                                                                                                                                               |
| ---------------------------- | ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Continuous spiral (`spiral`) | Boolean; **off** | Replaces independent parallel slice levels with a helicoidal field intended to join contours into longer, pen-down spiral paths. Singularities where the winding axis pierces the mesh remain boundaries. It is unavailable with curved or intrinsic fields, divergence, slice-plane modulation, or line-weight variation. |
| Remove hidden lines (`hide`) | Boolean; **on**  | Uses a depth buffer to remove contour and silhouette sections occluded from the current camera view. Turning it off is faster and shows paths through the model.                                                                                                                                                           |
| Add outer silhouette (`sil`) | Boolean; **on**  | Adds projected mesh boundary and front/back-facing transition edges in the ink colour. Hidden-line removal also applies to the silhouette when enabled.                                                                                                                                                                    |

## Output

### Line style and colour

| Parameter (ID)                                  | Type and default                       | What it does                                                                                                                                                                                                                                                              |
| ----------------------------------------------- | -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Stroke (`sw`)                                   | Number; **0.35 mm**; 0.05–2, step 0.05 | Sets SVG stroke width. It also influences the minimum dash and gap sizes produced by the halftone effect. G-code follows path centre-lines, so this value does not change physical pen width.                                                                             |
| Line-weight variation (`lineWeightMode`)        | Select; **Uniform · off**              | Optionally varies SVG contour widths. **Index contours** emphasizes every configured interval like major contours on a map; **Thickness wave** changes weight periodically; **Centre weighted** emphasizes the middle of the slice range. G-code remains centreline-only. |
| Interval (`lineWeightInterval`)                 | Integer; **5**; 2–20                   | Sets which contour is emphasized in Index mode, or the number of contours per cycle in Thickness wave mode.                                                                                                                                                               |
| Variation (`lineWeightAmount`)                  | Number; **100%**; 0–300, step 5        | Sets the maximum increase above the base Stroke width. At 100%, the thickest contours are twice the base width.                                                                                                                                                           |
| Ink colour (`color`)                            | Colour; **#15181a**                    | Sets the base contour and silhouette colour. Accepts a colour-picker value or a valid 3/6-digit hex entry; stored/exported values are normally six-digit hex. Blueprint stock uses white ink unless a gradient is enabled, and chromatic aberration adds RGB copies.      |
| Background colour (`backgroundColor`)           | Colour; **#ffffff**                    | Sets the preview sheet colour and the exported background rectangle when **Include sheet background** is enabled. Chromatic aberration uses black when it is the active document effect; blueprint stock takes precedence when both effects are enabled.                  |
| Use colour gradient (`gradientEnabled`)         | Boolean; **off**                       | Colours contours by normalized slice position. It may be combined with every post-processing effect. With chromatic aberration, the gradient remains as the central artwork beneath the displaced RGB copies. G-code groups sampled colours as separate pen/tool groups.  |
| Colour by line index (`lineIndexColorEnabled`)  | Boolean; **off**                       | Overrides the ink or gradient colour for selected contour numbers or number series. Line numbers are one-based and follow the slice order; imported SVG centrelines use their run order. The override also creates separate plotter pen/tool groups.                      |
| Line colour target (`lineIndexColors[].series`) | Choice; **Specific line**              | Targets one line or all **Even**, **Odd**, **Prime**, **Fibonacci**, or **Tribonacci** line numbers. Fibonacci begins 1, 2, 3, 5… and Tribonacci begins 1, 2, 4, 7….                                                                                                      |
| Reverse series (`lineIndexColors[].reverse`)    | Boolean; **off**                       | For an automatic series, counts matching positions backwards from the final line. For example, reversed Prime targets the 2nd, 3rd, 5th, and subsequent prime-numbered lines from the end.                                                                                |
| Line index colour (`lineIndexColors`)           | Line 1–9999 and colour; **1, #ef4444** | Assigns a six-digit hex colour to the selected line or series. Add as many rows as needed; later rows win wherever targets overlap.                                                                                                                                       |
| Gradient preset                                 | Choice; **Rainbow**                    | Replaces all gradient stops with Rainbow, Sunset, Ocean, Earth, or Mono. Editing a stop clears the active preset label without changing the result.                                                                                                                       |
| Gradient stop colour                            | Colour; preset-dependent               | Sets a stop's six-digit hex colour.                                                                                                                                                                                                                                       |
| Gradient stop position                          | Integer percent; **0–100**, step 1     | Places a stop along normalized slice depth/height. Stops are kept sorted. There must be at least two stops; **Add colour stop** inserts a copy of the preceding colour at the midpoint of the widest gap.                                                                 |
| Pen colours (`gradientColors`)                  | Integer; **6**; 2–24                   | Samples the continuous gradient into this many discrete colours, producing separate plotter-ready path groups.                                                                                                                                                            |

When randomization enables or preserves the gradient, it creates a new harmonic gradient anchored to the current Ink colour instead of choosing one of the fixed presets.

The default Rainbow stops are red at 0%, amber at 20%, lime at 40%, cyan at 60%, blue at 80%, and violet at 100%.

| ----------------------------------------- | ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

Direct dimension edits switch the selector to Custom unless they exactly match a preset.                                                           |
| Width (`pw`)                              | Number; **210 mm**; 10–2000, step 1 | Sets the SVG/G-code sheet width and the projection coordinate system.                                                                                                                                                                                    |
| Height (`ph`)                             | Number; **210 mm**; 10–2000, step 1 | Sets the SVG/G-code sheet height and the projection coordinate system.                                                                                                                                                                                   |
| Margin (`margin`)                         | Number; **14 mm**; 0–40, step 1     | Insets the 1× projection fit from the artboard edge. ### Generative mask

| Parameter (ID)                                               | Type and default                    | What it does                                                                                                                                                                                     |
| ------------------------------------------------------------ | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Clip to generative shape (`maskEnabled`)                     | Boolean; **off**                    | Clips contour, centreline, annotation, SVG, and G-code geometry to a generated closed boundary. The sheet background and blueprint document furniture remain unmasked.                           |
| Draw mask outline (`maskOutline`)                            | Boolean; **off**                    | Draws the generated boundary with the active ink and stroke width. The closed path is included in SVG and G-code output and follows every morph instance.                                        |
| Roundness (`maskRoundness`)                                  | Number; **100%**; 0–100, step 1     | Morphs the base superellipse from an almost rectangular boundary at 0% to an ellipse at 100%. On a square mask this produces the requested rectangle-to-circle range.                            |
| Width / Height (`maskScaleX` / `maskScaleY`)                 | Number; **100%**; 10–100, step 1    | Scales the mask inside the margin-adjusted artboard independently on each axis.                                                                                                                  |
| Offset X / Y (`maskOffsetX` / `maskOffsetY`)                 | Number; **0%**; −100–100, step 1    | Moves the mask centre horizontally or vertically by a percentage of the available half-width or half-height. The mask may extend beyond the sheet; artboard clipping still applies when enabled. |
| LFO 1/2 amplitude (`maskLfo1Amplitude`, `maskLfo2Amplitude`) | Number; **0%**; 0–45, step 1        | Adds or removes radial boundary distance as each oscillator travels around the mask. Combining different cycle counts produces irregular, repeatable blobs.                                      |
| LFO 1/2 cycles (`maskLfo1Cycles`, `maskLfo2Cycles`)          | Number; **3 / 5**; 1–12, step 0.25  | Controls angular lobes. Fractional values continuously crossfade adjacent integer harmonics, keeping the generated boundary closed during a morph.                                               |
| LFO 1/2 phase (`maskLfo1Phase`, `maskLfo2Phase`)             | Number; **0° / 90°**; 0–360, step 1 | Rotates each oscillator independently around the boundary.                                                                                                                                       |
| LFO 1/2 wave morph (`maskLfo1Waveform`, `maskLfo2Waveform`)  | Number; **0%**; 0–100, step 1       | Continuously morphs each oscillator from sine at 0%, through triangle at 50%, to a rounded square wave at 100%.                                                                                  |

All numeric mask parameters support X and Y morph targets. This allows one morph dimension to change the base silhouette—for example rectangle to circle—while the other independently introduces or transforms boundary irregularity.

### Post-processing

| Parameter (ID)                     | Type and default                    | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ---------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Slice explode (`explodeAmount`)    | Number; **0%**; 0–300, step 1       | Separates contour layers in 3D before camera projection. Planar fields use their constant normal; spherical and cylindrical fields use the local outward gradient and leave axis/centre singularities unmoved. It is disabled for geodesic fields because they do not yet provide a reliable local gradient. At 100%, the scalar-level spacing is doubled. Hidden-line selection still follows the source surface, and displaced geometry is included in SVG and G-code. Continuous spiral is unavailable above 0%. |

G-code exports these as continuous paths because SVG dash styling is not converted into segmented toolpaths.                                                                                                                                                                                                            |

| Contrast (`halftoneContrast`)      | Number; **75%**; 0–100, step 1      | Controls how much dash-to-gap ratio varies among tone bands. All effect toggles can be enabled together. Randomization samples them independently while preserving individual locks.

## Randomization, locking, and history

- **Randomize parameters** changes creative view, contour, colour, and effect settings within curated subranges. It deliberately keeps the loaded source and physical sheet dimensions stable. Its ranges can be narrower than the manual control ranges.
- The dice button in a group header applies the same curated randomization only to that group's parameters. Parameters in other groups remain unchanged.
- An open-lock button means the parameter participates in randomization. Clicking it shows a closed lock and excludes the base value—and any active morph target for that parameter—from later randomization.
- **Lock all** and **Unlock all** temporarily set every randomization lock at once. Click the active bulk button again to restore the previous individual lock set. Changing an individual lock ends that temporary bulk state; the next bulk action starts from the newly edited set.
- Randomization locks are available for morphable numeric/colour controls (including wavefront centres, cylinder orientation, both geodesic seed directions, focal length, perspective, Klein↔Poincaré warp, and lens distortion), Geodesic mode, Divergence, Background colour, Gap easing, Slice field, slice-plane modulation, Line-weight variation, Continuous spiral, Remove hidden lines, Add outer silhouette, Use colour gradient, Halftone stroke, Chromatic aberration, Humanizer, Technical blueprint, and Topographic map.
- **Undo** and **Redo** keep up to 100 snapshots of render parameters. Source selection, SVG extrusion, model up axis, paper preset as a label, export format/profile, and G-code-only values are not part of those snapshots.
- **Named snapshots** save the current render parameters, X/Y morph configuration, and randomization locks in the browser's IndexedDB storage. Each entry keeps its name and creation date and can be restored or deleted later. Like undo/redo, named snapshots do not replace the loaded source or export-machine settings.
