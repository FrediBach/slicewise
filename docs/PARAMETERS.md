# Slicewise parameter reference

This document describes the user-facing parameters in Slicewise as implemented in `src/App.tsx` and `src/lib/slicer.ts`. Ranges are the limits enforced by the interface. Unless noted otherwise, changing a parameter redraws the preview and affects both SVG and G-code output.

Select controls show a short information banner for the active option. The banner updates after direct selection, randomization, snapshot restoration, and undo or redo.

## Workspace modes

The top workspace switch offers Config, Animation, and Sequencer. Sequencer keeps the contour controls editable and turns the latest exact contour result into a deterministic phrase. Quick interaction previews never replace the musical source. If an exact result arrives during playback, its lane grids appear immediately and the sounding phrase changes at the next unscheduled global bar.

The Sequencer transport provides play/pause, return to start, a bar/beat readout, and tempo from **40–240 BPM** (default **110**). Space toggles playback, Home returns to the start, and Left/Right move by one sixteenth-note transport step when focus is not in a form control. Web Audio is created only by the Play gesture and is closed on leaving Sequencer mode.

Each lane exposes its melodic/drum type, **1–64** steps, **0–Steps** Euclidean pulses, mute, solo, deletion, and an accessible step grid. The initial project contains one contour-mapped pluck lane and one synthesized kick lane. Add Melody and Add Drum create independent rows. Changing lane type uses that type's explicit defaults while retaining shared rhythm, timing, probability, mute, solo, direction, and contour-influence settings.

Imported meshes are welded, centred on their bounding-box midpoint, and uniformly normalized to a bounding-sphere radius of 1. Original model units therefore do not determine output size; artboard, margin, scale, and offsets do.

Built-in demo meshes include Torus knot, Ripple sphere, Rounded cube, Soft diamond, Ring torus, Twisted bloom, Hourglass, Tetrapod, and Radish. They are deterministic, closed procedural meshes and initially use Z-up orientation.

## Animation

The workspace mode switch changes between static configuration and timeline animation. Entering Animation mode freezes the current render settings, disables non-morphable controls, suppresses the overlaid X/Y Morph feature for animation frames, and creates a protected keyframe at time zero. Returning to Config mode restores the frozen settings without applying keyframe edits to them.

| Parameter                   | Type and default       | What it does                                                                                                                                                   |
| --------------------------- | ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Duration                    | Number; **5 s**        | Sets the timeline length. It cannot be shortened past the final keyframe.                                                                                      |
| FPS                         | Integer; **30**; 1–120 | Sets the playhead step and video-export frame rate. Preview playback remains clock-based and may drop visual frames when contour rendering lags.               |
| Playhead                    | Timeline range         | Scrubs through calculated in-between settings. Controls are read-only between keyframes.                                                                       |
| Add keyframe                | Action                 | Captures every morphable value at the current calculated playhead state and selects the new keyframe for editing.                                              |
| Duplicate selected keyframe | Action                 | Copies the complete selected keyframe one frame later when that time is available, otherwise at the nearest earlier free frame.                                |
| Delete selected keyframe    | Action                 | Removes the selected keyframe. The keyframe at time zero is protected.                                                                                         |
| Outgoing easing             | Choice; **Linear**     | Applies Linear, Ease in, Ease out, Ease in & out, or Hold timing to the segment after the selected keyframe. The final keyframe has no outgoing segment.       |
| Loop                        | Boolean; **on**        | Restarts preview playback at time zero after the duration. It defaults off when the system requests reduced motion.                                            |
| Play / pause                | Action                 | Previews the animation with quick worker renders and settles on an exact render when paused.                                                                   |
| Export video                | Action                 | Renders every frame exactly and downloads an opaque, silent WebM at the artboard aspect ratio with a 1080-pixel long edge. VP9 is preferred with VP8 fallback. |

Keyframe diamonds can be selected or dragged along the timeline; occupied times are rejected and the time-zero keyframe cannot move. Space toggles playback, arrows step one frame, Shift + arrows step ten frames, K adds a keyframe, Delete/Backspace removes the selection, Home/End jump to the timeline boundaries, and Ctrl/⌘ Z handles animation-scoped undo while Animation mode is active.

Numeric parameters interpolate linearly. Integer counts round after interpolation. Ink colour interpolates per RGB channel. Seed parameters hold their earlier value until the next keyframe so seeded geometry does not reshuffle continuously. Video export is available when the browser exposes WebCodecs VP9 or VP8 encoding; unsupported browsers retain timeline editing and playback. Export runs sequentially, remains local to the browser, and can be cancelled.

The current animation project autosaves locally after timeline edits. Slicewise associates it with a generated browser-local workspace ID rather than a source filename, migrates stored version-one data on load, and restores it when its frozen base settings match the current Config snapshot. Animation data stays separate from ordinary named parameter snapshots, and uploaded source mesh or artwork bytes are not stored with it. See `docs/ANIMATION.md` for the persistence, interpolation, and export contracts.

| Projection warp (`projectionWarpMode`)         | Choice; **None**                       | Selects one exclusive camera-space projection warp: None/orthographic, Klein ↔ Poincaré, Hyperbolic Möbius, stereographic, gnomonic, Lambert azimuthal equal-area, or circle inversion. | Klein ↔ Poincaré (`lensWarpExponent`)          | Number; **0%**; 0–100, step 1          | With the matching projection mode selected, applies a radial disk-model warp after perspective. 0% preserves Klein coordinates; 100% uses the standard Klein-to-Poincaré radius conversion; intermediate values use a continuous multiplicative exponent.                                         |
| Hyperbolic direction (`mobiusDirection`)       | Number; **0°**; −180–180, step 1       | Sets the polar direction of the Möbius disk-translation parameter.                                                                                                                                                                                                                                |
| Hyperbolic displacement (`mobiusDisplacement`) | Number; **0%**; 0–95, step 1           | Sets the disk-translation magnitude. The 95% maximum stays safely inside the open Poincaré disk while allowing strong asymmetric navigation.                                                                                                                                                      |
| Hyperbolic rotation (`mobiusRotation`)         | Number; **0°**; −180–180, step 1       | Rotates the translated Poincaré disk counter-clockwise.                                                                                                                                                                                                                                           |
| Warp strength (`mobiusStrength`)               | Number; **100%**; 0–100, step 1        | Interpolates the Möbius translation and rotation parameters from identity at 0% to their selected values at 100%. | Spherical strength (`sphericalStrength`)       | Number; **100%**; 0–100, step 1        | Blends normalized camera-plane coordinates into the selected exact spherical projection. 0% is neutral and 100% reaches the analytic endpoint.                                                                                                                                                    |
| Inversion centre X/Y (`inversionCenterX/Y`)    | Number; **0%**; −100–100, step 1       | Places the inversion centre in normalized camera space as percentages of model radius. Camera orientation already controls the projection orientation.                                                                                                                                            |
| Inversion radius (`inversionRadius`)           | Number; **50%**; 1–200, step 1         | Sets the circle fixed pointwise by inversion. Points inside and outside exchange according to `R² / distance²`.                                                                                                                                                                                   |
| Inversion strength (`inversionStrength`)       | Number; **100%**; 0–100, step 1        | Blends from identity to exact circle inversion. Paths approaching the inversion centre are split before their coordinates diverge.                                                                                                                                                                |
| Lens distortion (`lensDistortion`)             | Number; **0%**; −100–100, step 1       | Applies continuous radial optical distortion after the selected projection warp. Negative values create barrel distortion, 0% is neutral, and positive values create pincushion distortion.                                                                                                       |

Canvas gestures provide equivalent controls: drag to change azimuth/elevation, Shift-drag to roll, Space-drag to offset, and use the mouse wheel to scale. Double-click resets Scale and both offsets, but leaves orientation unchanged.

For a classic isometric view, set Perspective to 0%, Lens distortion to 0%, Azimuth to 45°, Elevation to 35.3°, and Roll to 0°. Other orthographic azimuth/elevation combinations produce dimetric, trimetric, plan, and elevation views.

All listed modes are projection warps of the rendered Euclidean mesh, not replacements for its intrinsic geometry or contour metric. The fixed order is camera basis, orthographic/perspective blend, the selected projection warp, optical lens distortion, then sheet scale and offset. None is the ordinary orthographic/perspective camera result and therefore doubles as the orthographic choice when Perspective is 0%.

For spherical modes, normalized camera-plane radius `r` lifts through the sphere's exponential map at angular distance `ρ = πr/2`; `r = 1` is the spherical horizon. Stereographic uses `(X/(1+Z), Y/(1+Z))`, gnomonic uses `(X/Z, Y/Z)` on the front hemisphere, and the horizon-normalized Lambert equal-area model uses `(X/√(1+Z), Y/√(1+Z))`. Camera azimuth, elevation, and roll already orient this construction, so there is no redundant spherical orientation control. Stereographic and Lambert split at their antipodal singularity; gnomonic splits at the horizon. Extremely large singular samples are rejected before sheet scaling.

At the Klein ↔ Poincaré 100% endpoint the disk-model relation is `p = k / (1 + sqrt(1 − k²))`. Möbius uses `z′ = exp(iθ) · (z − a) / (1 − conjugate(a) · z)` with a bounded translation parameter `a`. Circle inversion uses `c + R²(p−c)/|p−c|²`. Nonlinear spans are adaptively subdivided according to Curve quality before visibility and output processing, so preview, SVG, and G-code follow the warped curve rather than connecting distant transformed endpoints with straight chords. Hidden-line depth faces are also subdivided for spherical and inversion modes near nonlinear domains.

## Contours

### Density and finish

| ------------------------- | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Line count (`lines`)      | Integer; **40**; 1–200 | Sets the number of slice levels. In spiral mode it sets the number of turns in the helicoidal slicing field. Higher values increase density and render cost.                                                                  |

**Distance difference** uses the symmetric range `[-max(|dA − dB|), +max(|dA − dB|)]`, ignores Gap easing, and always includes the meaningful zero contour. When Line count is even, one additional level is emitted so the family remains paired around zero. **Voronoi boundary** emits one explicit boundary family, so Line count and Gap easing are disabled. Equal-distance nearest-source ties belong to the lower seed vertex. Components unreachable from both seeds are omitted; difference and Voronoi output is empty when the seeds do not share a connected component. Curvature fields mask open-boundary, isolated, degenerate, and non-manifold samples. Their displayed values are dimensionless after robust normalization; raw Gaussian and mean curvature still obey inverse-square and inverse-length scale laws respectively.

### Path construction

G-code uses millimetres, absolute positioning, and feed-per-minute mode (`G21`, `G90`, `G94`). Separate colour groups pause with `M0` for a pen change. Export comments report optimized pen-up distance and whether clipping is active. Every file begins with the pen-up command and ends by returning to X0 Y0, then issuing `M2`. With expressive 3-axis motion enabled, UUNA TEK strokes lower to Contact Z and emit coordinated `G1 X… Y… Z… F…` drawing moves; travel remains XY-only at Pen up Z. Files record the manually configured angle, resolved machine tilt direction, compensation state, contact height, pressure depth, and ramps, but never emit a pen-angle motor command.

When G-code is selected, **Machine preflight** independently parses the serialized file before it can be copied or downloaded. It rejects unsupported commands, malformed or non-finite values, incomplete setup, incorrect feeds or pen heights, pen-down rapid travel, out-of-sheet compensated carriage motion, a final machine layout larger than the selected working envelope, invalid expressive setup, pressure outside the configured Z range, unsafe pen changes, and unsafe shutdown. Its machine-path preview shows the actual post-rotation layout, distinguishes pen-down drawing from dashed pen-up travel, colours expressive drawing into low/medium/high pressure bands, and reports dimensions, distances, lifts, Z range, maximum pressure, maximum observed Z slope, warnings, and estimated motion time. Rotated files also include a G-code layout comment. This software check cannot detect physical registration, real contact pressure, holder geometry, belt tension, or paper flatness; run calibration and a pen-free dry run, confirm placement in Universal Gcode Sender, and frame the sheet with the pen raised before plotting.

**Direct connection · GRBL** uses the Web Serial API to connect at 115200 baud and send the same preflight-validated G-code directly to the selected plotter. Slicewise strips comments for the controller and sends one command at a time, advancing only after GRBL replies `ok`; controller `error:` and `ALARM:` responses stop the stream with the source line and command. Sending requires a separate motion confirmation. Expressive confirmation additionally identifies the required physical angle and resolved machine direction, emitted Z range, compensation state, and calibration requirement. At each `M0` pen-change pause, it waits for the operator to change the pen and explicitly confirm before sending GRBL cycle start (`~`). **Stop** immediately requests GRBL feed hold (`!`) and cancels further commands; because feed hold freezes the current machine state, the pen may remain down. Web Serial currently requires a supporting desktop browser such as Chrome or Edge and a secure context (HTTPS or localhost). Port permission, model data, and G-code remain local to the browser.

## Randomization, locking, and history

- **Randomize parameters** changes creative view, contour, colour, and effect settings within curated subranges. It deliberately keeps the loaded source and physical sheet dimensions stable. Its ranges can be narrower than the manual control ranges.
- The dice button in a group header applies the same curated randomization only to that group's parameters. Parameters in other groups remain unchanged.
- An open-lock button means the parameter participates in randomization. Clicking it shows a closed lock and excludes the base value—and any active morph target for that parameter—from later randomization.
- **Lock all** and **Unlock all** temporarily set every randomization lock at once. Click the active bulk button again to restore the previous individual lock set. Changing an individual lock ends that temporary bulk state; the next bulk action starts from the newly edited set.
- Randomization locks are available for morphable numeric/colour controls (including wavefront centres, cylinder orientation, both geodesic seed directions, curvature smoothing/range/contrast, focal length, perspective, every projection strength/centre/radius, Klein↔Poincaré warp, lens distortion, Block, Scan-band, Staggered-slice, Wraparound-tear, Tile-shuffle, Sample-and-hold, and Misregistration geometry/colours where applicable, Kaleidoscope controls, and all vector zoom positions/dimensions/margins/guide colours), Projection warp, Geodesic mode, Curvature field, Include zero curvature, Divergence, Background colour, Gap easing, Slice field, slice-plane modulation, Line-weight variation, Continuous spiral, Remove hidden lines, Add outer silhouette, Use colour gradient, Block glitch and its direction/destination clearing, Scan-band glitch and its orientation, Staggered slices and its orientation/pattern, Wraparound tear and its orientation, Tile shuffle, Sample-and-hold and its axis, Misregistration and its copy scope, Kaleidoscope, every Vector zoom slot/shape/corner, Halftone stroke, Chromatic aberration, Humanizer, Technical blueprint, and Topographic map.
- **Undo** and **Redo** keep up to 100 snapshots of render parameters. Source selection, SVG extrusion, model up axis, paper preset as a label, export format/profile, and G-code-only values are not part of those snapshots.
- **Named snapshots** save the current render parameters, X/Y morph configuration, and randomization locks in the browser's IndexedDB storage. Each entry keeps its name and creation date and can be restored or deleted later. Like undo/redo, named snapshots do not replace the loaded source or export-machine settings.
